## ライブラリの方針（プロトコルの事実ではない）

照合の対象ではないが、事実が分かったら見直す値。

| 項目                     | 値                               | 理由                                                                          |
| ------------------------ | -------------------------------- | ----------------------------------------------------------------------------- |
| 応答 1 行の上限          | 16 KiB（終端込み）               | 終端を送らない相手に対してメモリを有限にする。P-25 が分かったら見直す         |
| 既定の接続タイムアウト   | 5 秒                             | `KvConfig::default()`                                                         |
| 既定の応答タイムアウト   | 2 秒（送信から終端まで）         | `KvConfig::default()`                                                         |
| モックの応答の書式       | ゼロ詰め・符号付きは `+`/`-`     | 詰め物ありでもクライアントが解析できることを確かめるため（実機の書式は P-08） |
| モックのエラーの割り当て | 文法違反 `E1`、アドレス違反 `E0` | モックの選択。実機の割り当ては未照合                                          |

4. P-26 が分かったら `f32` とワード順を足す（`KvValue` に型を足す）。
5. 全行が照合済みになったら README の 状態 行を更新する。
