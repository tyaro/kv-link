## 出典

- 「KV-XLE02 ユーザーズマニュアル」13 章「上位リンク通信機能」
  （文書番号 `AS_166260_KV-XLE02_UM_084A11_KJ_JP_2036_1`）。表の `KV-XLE02 UM 13-xx` はこの
  マニュアルのページ番号。
- このマニュアルは **KV-XLE02**（イーサネットユニット）のもの。KV-8000 などの CPU 内蔵
  イーサネットポートや KV-LE21V などの他のユニットでも同じコマンド体系と仮定しているが、
  **その仮定は未照合**（それぞれのマニュアルで確かめるまで「対応済み」と書かない）。

この表がプロトコル事実の唯一の正。コード側の定数は `src/protocol.rs` に集めてあり、

この表と `src/protocol.rs`（と影響するテスト）を同じ PR で直す。

## 利用側への注記（プロトコルの事実、ライブラリは扱わない）

- TCP のソケット数は 15 で、Modbus サーバ機能・MC プロトコル/SLMP 通信機能と共用（13-3、13-4）。
  接続を張りっぱなしにする数に注意する。
- ユニット側に受信タイムアウト（0〜59 s、初期 10 s）とキープアライブ（0〜65535 s、初期 600 s）の
  設定がある（13-3、13-4）。長く無通信だとユニット側から切られうるので、再接続は利用側
  （banto）の責務として持つ。
- クライアントが接続を閉じると、ユニットは自動で閉じて接続待ちに戻る（13-6〜13-8）。

## ライブラリの方針（プロトコルの事実ではない）

照合の対象ではないが、事実が分かったら見直す値。

| 項目                               | 値                                                              | 理由                                                                                                                                         |
| ---------------------------------- | --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 応答 1 行の上限                    | 16 KiB（終端込み）                                              | 終端を送らない相手に対してメモリを有限にする。型付き API の最大の正しい応答（`.S` × 1000 点 = 7,001 バイト）が収まることをコンパイル時に検査 |
| 応答トークンの解析                 | 固定幅より長いものは `Framing`、短い形（ゼロサプレス）は受理    | 長いトークンはずれの兆候。短い形を拒んでも安全性は上がらず、他ユニットで詰め方が違った場合に接続を失うだけ（P-08）                           |
| 奇数番地の 32 bit アクセス         | 送らずに `InvalidRequest`                                       | 同時性の保証が無い（P-32）。緩めるときは定数を変えずに明示的なオプトインを足す                                                               |
| `f32` の書き込み値                 | NaN を含むどのビット列も断らない                                | 解釈するのはラダー側。このクレートは値の意味に立ち入らない                                                                                   |
| ビットデバイスのワード形式         | 使わない（`bool` はビット、数値型はワードデバイスだけ）         | v0 の制限（P-14）。プロトコル上は可                                                                                                          |
| 既定の接続タイムアウト             | 5 秒                                                            | `KvConfig::default()`                                                                                                                        |
| 既定の応答タイムアウト             | 2 秒（送信から終端まで）                                        | `KvConfig::default()`                                                                                                                        |
| モックの応答の書式                 | マニュアルどおりの固定幅（P-08）                                | マニュアルの例（`+15025 -25400 +00000`・`1 0 1 0`）をそのまま再現する                                                                        |
| モックのエラーの割り当て           | 範囲外 `E0`、未知のコマンド `E1`、点数の上限外・値の範囲外 `E1` | 前の 2 つはマニュアルの説明どおり。点数・値の範囲外にどちらが返るかはマニュアルに無く、モックの選択                                          |
| モックのビットデバイスのワード形式 | 未実装（`E0`）                                                  | ライブラリはその要求を送らない                                                                                                               |
